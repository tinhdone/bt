## Kỹ thuật
- HTML5 Semantic
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Responsive Desktop / Tablet / Mobile
- Đường dẫn tương đối
- Ảnh điểm đến (Huế, Hội An, Đà Nẵng, Phong Nha, trang chủ, trang giới thiệu) là ảnh thật, lấy trực tiếp (hotlink) từ Wikimedia Commons, có ghi nguồn
- Ảnh 4 món ăn (`images/cao-lau.jpg`, `mi-quang.jpg`, `banh-beo.jpg`, `bun-bo-hue.jpg`) là ảnh thật do nhóm sưu tầm và lưu trực tiếp trong thư mục `images/`
- `images/food.svg` không còn được dùng ở trang nào, giữ lại trong thư mục phòng khi cần dùng sau

## Triển khai GitHub Pages
Đưa toàn bộ thư mục lên repository, giữ nguyên cấu trúc `css/` và `images/`. Trong GitHub chọn Settings → Pages → Deploy from a branch → chọn branch chứa website và thư mục `/root`.
